## 青龙脚本：token 缓存改为不落盘（每次重登）

- 背景：本仓库是 docker 青龙脚本。排查确认 2 个脚本会本地落盘存 token：
  - `miniprogram/wxbbs.py` → `wxzftxbbs_account_info.json`（明文 session_token）
  - `miniprogram/exijiu_jg.py` → `xijiutoken.json`（JWT token + `_daily` 每日去重标记）
  其余 3 个不存 token：`app/oclean_sign.py`（每次从环境变量 OCLEAN_COOKIE 读）、`miniprogram/cdf.py`（注释明确不缓存）、`miniprogram/exijiu_jph.js`（每次重登，Env 框架的 box.dat 未用于存储 token）。
- 改造（参照 cdf.py「每次重登」模式）：
  - **wxbbs.py**：删除 `save/load/remove_account_info` 三个方法及全部调用；`run()` 内每个账号强制 `get_code` + `login`；登录后 `get_balance` 校验，失效则重登一次（不落盘）。
  - **exijiu_jg.py**：删除 `CACHE_FILE/load_cache/save_cache/token_valid` 与 `cache` 字典；每个账号强制 `auto_login_with_retry` 重登；token 失效时当场重登重试（不写盘）。
- **关键取舍**：exijiu 的 `_daily`（今日已完成）去重标记原本与 token 同存一个 json，去掉落盘后改为 `do_daily=True`，依赖 `run()` 内部幂等（签到重复调用服务端判已签、分享有 `isTodayFirstShare` 上限），未额外加服务端查询——若以后发现一天多次 cron 日志刷屏，再考虑按 cdf.py 加 `get_today_done` 式服务端查询。
- **保留落盘项**（非凭证，未动）：exijiu 的 `xijiu_monthly.json`（月度酿酒累计，业务统计）、wxbbs 的 `notify.py` 下载（推送依赖，仅 LY_NOTIFY 开启且本地无 notify.py 时触发）。
- 验证：AST 语法校验两文件均 SYNTAX_OK；grep 确认无残留 token 落盘调用（只剩说明性注释）。
- 注意：`exijiu_jg.py` 文件首行带 UTF-8 BOM，用 `utf-8` 读 AST 会误报 `invalid non-printable character U+FEFF`，须用 `utf-8-sig`。
